# Relationship to the earlier project

This consolidated project builds on the existing Desktop folder `Typing vs Handwriting - Stage 1` and the earlier six-stage work. Original stage folders and course reference files were left unchanged. The consolidated copy is stored separately in the current project workspace.

The main estimate, Welch interval/test, within-person question-type contrast and lecture-adjusted coefficient reproduce the previous results. The adjusted figure retains the earlier HC3 interval with a normal critical value. Classical regression intervals are now additionally available and differ slightly because they use a different standard error and reference distribution.

New material includes explicit data provenance and checks, one organized visualizations directory, full-precision statistical tables, multiple-testing handling, model diagnostics, the interaction check, exploratory correlation and rank checks, categorical examples, power scenarios, interval comparisons, a detailed report and reproducibility documentation.
