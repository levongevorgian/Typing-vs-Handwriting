# Mapping to the course

Reference: IESM 324 Applied Statistics for Engineers, Ashot Abrahamyan, Fall 2026, August 2026 syllabus. The mapping reflects relevant syllabus topics; it does not imply every topic was delivered by a particular date.

| Syllabus topic | Application and saved evidence |
|---|---|
| Sampling, description, visualization | Data audit; descriptive_statistics.csv; figures 01–02 |
| Probability, independence | Independent groups; paired question-type scores; design assumptions |
| Propagation of uncertainty / linear combinations | Welch SE; within-person gap preserves covariance; report section 9 |
| Distributions, point estimates, probability plots, CLT | t, normal, chi-square distributions; figure 03; assumptions discussion |

| Prediction and tolerance intervals | Figure 13; normal_model_intervals.csv; explicit normal-model limitations |

| Multiple regression | Condition and lecture predictors; classical and HC3 uncertainty; residual diagnostics |
| Factorial experiments | Fixed condition-by-lecture interaction nested F-test, exploratory |

| Bootstrap | Excluded at the user's request |

Counting exercises and instrument measurement-error propagation are not added as standalone analyses: they do not answer the selected question with the available data. Normal tolerance intervals are course illustrations and not literal guarantees for bounded quiz scores. No demographic effects or note-taking mechanisms can be analyzed without additional data.
